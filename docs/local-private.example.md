# Local Private Notes

This file is a template for machine-specific notes that should not enter version control.

## Suggested Content
- local `sudo` workflow notes
- personal shell aliases
- temporary ports or tunnels
- private tokens or test accounts that are not part of repository defaults

## Rules
- Copy this file to `docs/local-private.md` for your own machine.
- Do not commit `docs/local-private.md`.
- Do not place host-level passwords in versioned files such as `AGENTS.md` or `docs/runbook-local.md`.
